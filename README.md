# Eye Plus Óptico - Plataforma Web

Este projeto é a plataforma web oficial da **Eye Plus Óptico**, permitindo aos usuários conhecer os serviços da clínica, agendar consultas, encontrar lojas, consultar profissionais e acessar informações sobre saúde ocular.

O site foi desenvolvido usando **React**, **Vite**, **React Router** e componentes do **shadcn/ui**, com foco em responsividade, semântica e experiência do usuário.

## Funcionalidades

- Listagem de **serviços** da clínica com páginas dedicadas.
- **Agendamento de consultas** com escolha de loja, profissional e serviço.
- **Informações sobre lojas** com links para Google Maps.
- **Página Sobre** com informações da empresa e desenvolvedora.
- **Página de contactos** com e-mail e WhatsApp.
- **Header e Footer responsivos**, com menus dropdown e ThemeToggle.
- Suporte a **tema claro/escuro**.
- Layout totalmente **responsivo e semântico**.
- **Redes sociais** integradas (Facebook, Instagram, TikTok).
